BRIEF D'INTÉGRATION — CASE PÉDALE SUSTAIN (TOPBAR) — ÆTHER KEYS
=================================================================

1. OBJECTIF
-----------
Remplacer l'ancienne case « pédale » du Topbar (petite barre grise inclinée,
entre la case Loop/clavier et la case plume) par le nouveau composant Compose
SustainPedal. Le composant est un dessin 100 % Canvas (aucun PNG), animé par la
valeur MIDI CC64 (0..127).

Périmètre : UNIQUEMENT cette case. Ne touche à aucune autre case du Topbar, ni
aux icônes, logos, tailles ou couleurs hors de ce composant.

2. FICHIER FOURNI
-----------------
SustainPedal.kt  (package com.aetherkeys.topbar — adapte le package si besoin)

Signature :
  SustainPedal(
      value: Int,                       // CC64, 0..127
      modifier: Modifier = Modifier,
      caseSize: Dp = 96.dp,             // côté INTÉRIEUR ; case réelle = caseSize + 2.dp (bordure)
      accent: Color = Color(0xFF8F7BFF),// LED + lueur
      label: String = "SUSTAIN",
      threshold: Int = 64,              // seuil d'allumage de la LED
      fontFamily: FontFamily = FontFamily.Default,
  )

3. ÉTAPES D'INTÉGRATION (dans cet ordre)
----------------------------------------
1) Avant toute modification : lister l'ancienne case pédale dans le Topbar
   (fichier, composable, handler de clic éventuel, taille, position, weight).
   Noter ces informations dans le rapport final.
2) Copier SustainPedal.kt dans le module UI, à côté des composants du Topbar.
3) Vérifier que le module compile avec les dépendances Compose déjà présentes
   (voir section 5 si une erreur apparaît).
4) Dans le Topbar, remplacer l'ancienne case par :
     SustainPedal(
         value = sustainValue,          // état existant du CC64 (voir section 4)
         caseSize = <taille adaptée>,   // voir section 6
         accent = <couleur d'accent de l'app>,
         fontFamily = <police globale Plus Jakarta Sans>,
     )
   Conserver position, ordre et espacement de l'ancienne case. Conserver aussi
   son comportement de clic existant s'il y en avait un (le composant ne gère
   aucun clic lui-même ; l'envelopper dans un Modifier.clickable / pointerInput
   fourni par l'appelant).
5) Ne supprimer l'ancien composant/asset de pédale QUE s'il n'est plus utilisé
   nulle part, et seulement après avoir listé son contenu et le dossier concerné.
   Ne rien supprimer d'autre sans demande explicite.

4. BRANCHEMENT MIDI (fait par Amiel — ne pas l'implémenter)
-----------------------------------------------------------
Le composant attend simplement un Int 0..127 (State ou valeur remontée par le
ViewModel). Prévoir uniquement le point d'entrée :
   val sustainValue: Int   // 0..127
Ne pas inventer de logique MIDI, ne pas lire de port, ne pas filtrer les
valeurs : Amiel branche le CC64 lui-même. En attendant, utiliser une valeur
d'état locale (0) pour que la case s'affiche au repos.
Pas de réinitialisation, de lissage ni de seuil supplémentaire côté appelant :
le composant gère déjà le ressort (appui ferme, retour plus doux) et le seuil.

5. IMPRÉVUS PROBABLES ET AJUSTEMENTS AUTORISÉS
----------------------------------------------
Le fichier n'a pas pu être compilé là où il a été écrit. Ajustements permis,
sans changer le dessin :

a) Import manquant ou ambigu → corriger l'import (lerp : androidx.compose.ui.util.lerp ;
   Path.combine / PathOperation : androidx.compose.ui.graphics).
b) mutableFloatStateOf introuvable (Compose runtime < 1.5) → remplacer par
   mutableStateOf(0f) avec `by`/`.value`, même logique.
c) drawText / rememberTextMeasurer introuvables (Compose UI < 1.3) → mettre à
   jour Compose, ou en dernier recours dessiner le label via
   nativeCanvas.drawText avec un Paint (même position : x=13, baseline y=15 en
   unités du repère 100, taille 6.4, semi-bold, letterSpacing 1.1, couleur
   #8793B3 à 80 %). Prévenir Amiel si cette solution est retenue.
d) Erreur sur withTransform ou clipPath → vérifier que ce sont bien les
   fonctions de androidx.compose.ui.graphics.drawscope.
e) Le Topbar parent coupe l'ombre extérieure de la case → autoriser le dépassement
   (clipToPadding = false / Modifier sans clipToBounds sur le parent) ou ajouter
   un padding de 4–8 dp autour de la case. Ne pas retirer l'ombre.
f) Aperçu Android Studio : les flous (BlurMaskFilter) ne s'affichent pas dans
   @Preview. C'est normal : valider sur appareil ou émulateur API 28+.
g) Appareils API 26–27 : lueurs en dégradé approché, ombres de la case omises.
   Comportement voulu, ne pas « corriger ».
h) Jank ou charge CPU anormale : le composant ne redessine que pendant le
   mouvement (état lu dans le bloc de dessin). Vérifier qu'aucun parent ne lit
   la valeur animée dans la composition. Ne pas ajouter de remember/cache sans
   mesure.

Règle générale : tout ajustement doit préserver à l'identique les coordonnées,
couleurs, dégradés, épaisseurs de trait et constantes du ressort
(k=340/c=26 à l'appui, k=190/c=19 au retour). Si un correctif oblige à les
changer, ne pas le faire : le signaler dans le rapport.

6. TAILLE ET PLACE DANS LE TOPBAR
---------------------------------
- La case est carrée : largeur = hauteur = caseSize + 2.dp.
- Choisir caseSize pour que (caseSize + 2.dp) corresponde à la hauteur des
  autres cases carrées du Topbar. Si le Topbar impose un carré exact, régler
  caseSize = hauteur imposée − 2.dp.
- Le composant s'adapte à n'importe quelle taille (dessin vectoriel mis à
  l'échelle). Ne pas l'étirer avec un Modifier non carré.
- Libellés de l'interface en anglais (« SUSTAIN »). Ne pas traduire.

7. VALIDATION (captures à fournir à Amiel)
------------------------------------------
Tester sur appareil réel, avec une valeur injectée à la main :
  - valeur 0   : pédale relevée, LED éteinte, pas de lueur
  - valeur 64  : mi-course, LED allumée (seuil atteint)
  - valeur 127 : pédale enfoncée, tranche fine, lueur et liseré d'accent visibles
  - passage 0 → 127 → 0 : mouvement fluide, léger rebond, retour plus doux
  - changement de valeur en plein mouvement : pas de saut, pas de blocage
  - rotation/changement de taille d'écran : dessin toujours net, rien tronqué
Comparer chaque capture à l'aperçu SustainPedal.jsx (référence visuelle). Lister
les écarts constatés, sans les corriger au-delà de la section 5.
