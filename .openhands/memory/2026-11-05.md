### La mesure qui tranche : le potard Valhalla est PLAT
Sur `/workspace/dl/valhalla/room_24.jpg` (coupe à y=335) : disque **uniforme 121**
sur panneau **52**, puis le liseré. Aucun dégradé de corps, aucun dôme, aucune
collerette. Le potard ne se lit que par : disque plus clair que le panneau +
filet clair au bord + arc de valeur + aiguille blanche. C'est l'inverse du
neumorphisme 3D (puits creusé / corps bombé / collerette / dôme) qui était en
place. **Règle** : pour ce design, mesurer la luminance du disque au centre ET au
bord ; si le centre est bien plus clair que le bord, c'est un dôme, pas un potard
plat.

### Session FX Design (suite) — page pleine, cellules séparées, potard plat

Commit `5dde12f` (branche `design/fx-reverb`, PR #6 mise à jour, **pas** sur main).

**Le vrai bug du potard : la luminance du disque.** Mesure sur `room_24.jpg` :
disque **121** / panneau **52** = rapport **2,3**. Notre première version était à
**40** — le disque se confondait avec le panneau, d'où « le potard ne ressemble à
rien ». Corrigé : `FxC.knobDisc = #6E7484` (~110). Autres faits mesurés, tous
vérifiés : **pas de liseré** (transition franche 1 px, un filet clair était une
invention) ; **aiguille sombre** sur le disque clair (jamais blanche) ; l'indicateur
de valeur est un **coin plein** au bord (rayon 28→57 sur un disque de 54, largeur
~25°), pas un arc d'épaisseur constante ; course 135°→405°.

**Le gros potard est la MÊME pièce que les petits.** `drawFxKnob(DrawScope, v,
accent, hot)` dans `FxKnob.kt` est partagé par `FxKnob` et `FxMagmaKnob` (deux
échelles). La version intermédiaire dessinait une « braise » à trois lobes qui
tournaient : c'était une invention — Valhalla n'a pas deux sortes de potards.

**Géométrie.** `FxGeo.CELLS = 3` (à 2 colonnes les rangées écrasaient le potard :
**52 unités mesurées au lieu de 96**, sans que rien ne le signale). Le diamètre est
désormais **adaptatif** : `BoxWithConstraints` → `minOf(maxWidth, maxHeight −
KNOB_TEXT, KNOB)`. Résultat mesuré : gros potard **197**, potard de cellule **75**
(avant : 46). La page d'effet n'a **plus de bande d'en-tête** (`if (!inEffect)`) :
titre dans le corps, commandes (Save/preset/retour/fermeture) dans la colonne de
gauche, cellules sur toute la hauteur à droite.

**Style du titre par preset** : `FxPalette.titleSize/titleSpacing/titleWeight`.
Mesuré : Hall 237 unités de large, Shimmer 283 — le lettrage change bien.
